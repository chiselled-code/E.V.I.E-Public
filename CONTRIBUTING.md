# Helping E.V.I.E

Thank you for wanting to help. The most useful things you can do:

- **Report problems.** Use **For grown-ups → Report a problem** inside E.V.I.E, or the [problem form](https://github.com/chiselled-code/E.V.I.E-Public/issues/new?template=problem.yml). Wrong answers, spelling mistakes and things that are hard to see, hear or tap are all problems worth reporting.
- **Share ideas** in [Ideas](https://github.com/chiselled-code/E.V.I.E-Public/discussions/categories/ideas), and add your thoughts to other people's.
- **Check the curriculum.** If you teach and something doesn't match what the national curriculum for England asks for that age, please report it as a problem ("A wrong answer, fact or spelling") with the statement it should meet.

E.V.I.E's code is in a private repository, so we can't accept pull requests or code here.

Please follow the [code of conduct](CODE_OF_CONDUCT.md), and never post anything that identifies a child.
