# E.V.I.E: problems, ideas and questions

[E.V.I.E](https://chiselled-code.github.io/E.V.I.E/) (Everyone's Virtual Interactive Education) is a free set of learning games for children aged 3 to 11, guided by a friendly robot. It runs in your browser or as an app, with no accounts, no adverts and no tracking.

This repository is where parents, carers, teachers and learners can tell us what's working and what isn't. E.V.I.E's code is kept in a separate, private repository, so there is no code here.

## How to get in touch

| You want to… | Go to |
|---|---|
| Report something that isn't working, a wrong answer or a spelling mistake, or something that's hard to use or see | [Report a problem](https://github.com/chiselled-code/E.V.I.E-Public/issues/new?template=problem.yml) |
| Suggest a game, a subject or an improvement | [Ideas](https://github.com/chiselled-code/E.V.I.E-Public/discussions/categories/ideas) |
| Ask a question about using E.V.I.E | [Questions](https://github.com/chiselled-code/E.V.I.E-Public/discussions/categories/q-a) |
| Tell us about a security or privacy problem | [Privately, as described in SECURITY.md](SECURITY.md) |

The quickest way to report a problem is from inside E.V.I.E: open **For grown-ups**, then **Report a problem**. It fills in the version and the kind of device for you.

You need a free GitHub account to post. Anyone can read what's here without one.

## Please keep children's details out

Everything here is public and can be found by search engines. Please don't include a child's name, photo, school, age in years or anything else that could identify them. If a screenshot shows a learner's name, crop or cover it first. We'll remove anything that identifies a child as soon as we see it.

## What happens next

We read everything. Problems are labelled, checked and fixed in E.V.I.E's code, and the issue is closed with a note once the fix is published. E.V.I.E updates itself, so fixes reach every device without anyone doing anything. The grown-ups' page in E.V.I.E shows what changed in each version.

Please be kind: see the [code of conduct](CODE_OF_CONDUCT.md).
