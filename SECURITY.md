# Security and privacy problems

E.V.I.E runs entirely on your device: no accounts, no servers and no data sent anywhere. Even so, if you find a way that E.V.I.E could leak information, run something it shouldn't, or put a child at risk, please tell us privately rather than in a public issue.

**[Report it privately](https://github.com/chiselled-code/E.V.I.E-Public/security/advisories/new)** (GitHub's private reporting: only the maintainers can see it).

Please include what you found, how to make it happen, and the version (shown on the grown-ups' page in E.V.I.E). We'll reply as soon as we can, fix it, and credit you if you'd like.
